ОБНОВЛЕНИЕ НА GITHUB (замена файлов)
1. Репозиторий -> Add file -> Upload files. Перетащите папки www и electron, а также файлы package.json (они заменят старые). Commit changes.
2. Откройте .github/workflows/main.yml -> карандаш (Edit) -> Ctrl+A -> вставьте содержимое нового main.yml из архива -> Commit changes.
3. Actions -> дождитесь зелёной галочки -> Artifacts -> скачать casper-vpn-windows.
